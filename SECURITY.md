# Security policy

## Supported versions

This policy covers the current deployment at [uf.do](https://uf.do/) and the latest build from `main`. For a self-hosted installation, include the commit or build version in your report.

## Report a vulnerability

Send a private email to [contact@luizbizzio.com](mailto:contact@luizbizzio.com) with `URLForge security` in the subject. Keep vulnerability details out of public issues and discussions while we assess the report.

Include the affected page or feature, your browser and version, what you observed, and who could be affected. If the issue involves a URL, use an example with synthetic values. Keep credentials, private links, and personal data out of the report.
